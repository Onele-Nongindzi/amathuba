# Security and privacy review: Amathuba release 1.0 (2026-11-24)

Reviewer: Penny Tration (Claude) · Security decider: Onele Nongindzi · Scope: whole app at release 1.0, including C-01 to C-04.

## Checklist
| Area | Result |
|---|---|
| Secrets in code or history (vendor libraries excluded) | None found. No `.env` files. |
| Identity and access | No sign-in by design. `admin.html` is public but cannot publish anything; publishing needs the owner's GitHub access. |
| Personal data (POPIA) | CV, contact details, ID number, signature and initials are stored only in the user's browser. Nothing is sent to a server. Location is opt-in, rounded to 2 decimals and stored on the device only. |
| Third-party code | Libraries are vendored (no CDN at run time). One outside script: GoatCounter, loaded only on the live site. |
| Inputs and output encoding | User text is escaped before display. Links from the opportunities file are checked to start with http(s). WhatsApp and calendar links are URL-encoded. |
| Untrusted files (CV upload) | pdf.js runs with `isEvalSupported:false`, which mitigates the known pdf.js font vulnerability (CVE-2024-4367) in this version. Files are read on the device only. |
| Money and messages | None. The app never sends messages; users share through their own WhatsApp or share menu. |

## Findings
### F-SEC-01: Tracked application links accepted any text
- Severity: Low (affects only the user's own device)
- Fix: only http(s) links are shown as “Open advert”. Status: Fixed (C-04).

### F-SEC-02: GoatCounter script loaded without an integrity check
- Severity: Low. If the counter's host were compromised, a script could run on the live site.
- Mitigation: anonymous counting only; nothing personal is passed to it. Option: self-host `count.js` later.
- Status: Recommend the security decider accepts this risk for 1.0.

### F-SEC-03: Personal details stay on shared phones
- Severity: Low. On a shared phone or a digital-hub computer, the next person could see the previous user's CV and Z83 answers (including ID number).
- Fix: “Clear all my data from this phone” (C-03). Status: Fixed. Recommend volunteers use it after each person at a hub.

### F-SEC-04: Visitor counting is not mentioned to users
- Severity: Low (transparency). The counting is anonymous and cookie-free, but the footer no longer says so.
- Recommendation: consider a short privacy note (decider's choice). Status: Open, decider to decide.

### F-SEC-05: jsPDF 2.5.1 is behind the current release
- Severity: Low. Later releases fixed issues that need untrusted input; here jsPDF only formats the user's own text.
- Fix: upgrade (C-05). Status: Queued.

## Verdict
**Sign off for release 1.0**, with F-SEC-02 and F-SEC-04 for the security decider to accept or act on, and F-SEC-05 queued. No Critical or High findings.
