# Amathuba 1.1 release notes

Fixes from the first manual test cycle (tester: Maile TK).

- **Back button works:** the phone and browser back button now moves between steps, and each step has its own link (for example …/amathuba/#cv).
- **Phone and email checks:** a gentle message appears if a phone number is not a South African number or an email address looks wrong.
- **Job dates:** a warning appears if a job ends before it starts.
- **“Write one for me”:** asks for your education, a skill or the job you want first, so the summary is about you.
- **Skills:** each line of skills you type stays its own line on your CV.
- **Courses:** clearer hint to put each course on its own line.
