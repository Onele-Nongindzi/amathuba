# Amathuba 1.2 release notes

- **The CV check now fixes problems, not just finds them.** “Fix what I can” rewrites duties so they start with an action word (for example “Responsible for managing stock” becomes “Managed stock”, “I served customers” becomes “Served customers”) and writes a summary from your details, or shortens one that is too long.
- **“Fix it” or “Show me” on every red item:** fixes it straight away where it can, or takes you to the exact field to change.
- **Fairer checking:** duties starting with words like “Developing” or “Achieved” now count as action words.
- **Better generated summaries:** natural capital letters and wording, for example “Experienced as a shop assistant”.
